# Tic Tac Toe Game

## 📌 Project Overview

**Tic Tac Toe Game** is a simple and interactive web-based game built using **HTML, CSS, and JavaScript**. The project allows two players to play the classic Tic Tac Toe game in the browser with a clean and responsive user interface.

This project is ideal for beginners who want to practice:

* JavaScript game logic
* DOM manipulation
* Event handling
* Frontend UI design

---

# 🎮 Features

### ✅ Two Player Gameplay

* Player **X** and Player **O** can play turn-by-turn.

### ✅ Win Detection Logic

* Automatically detects:

  * Row wins
  * Column wins
  * Diagonal wins

### ✅ Draw Detection

* Displays draw result if all cells are filled without a winner.

### ✅ Restart Game

* Reset button to start a new game instantly.

### ✅ Interactive UI

* Smooth and responsive game board design.

### ✅ Lightweight Application

* No frameworks or external libraries used.

# ⚙️ Game Logic

The game uses JavaScript to:

* Track player turns
* Store board values
* Detect winning combinations
* Handle game reset functionality

### Example Winning Patterns

```javascript
[
  [0,1,2],
  [3,4,5],
  [6,7,8],
  [0,3,6],
  [1,4,7],
  [2,5,8],
  [0,4,8],

]
```
